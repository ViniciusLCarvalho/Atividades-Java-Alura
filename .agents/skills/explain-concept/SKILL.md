# Explicar Conceito

## Procedimento

1. **Identificar o nível atual** do estudante perguntando (se não estiver claro):
   - Nunca viu o conceito
   - Já ouviu falar mas não entende bem
   - Quer aprofundar algo que já conhece

2. **Analogia do mundo real**: Antes de qualquer código, criar uma analogia
   concreta e cotidiana que fixe a intuição do conceito.

3. **Exemplo de código mínimo**: Apresentar um snippet Java curto e focado
   **exclusivamente** no conceito sendo explicado. Sem distrações.
   - Usar comentários explicativos no código
   - Manter em no máximo 15-20 linhas

4. **Verificação de entendimento**: Fazer UMA pergunta curta ao final para
   confirmar se o conceito ficou claro. Exemplos:
   - "Com suas palavras, qual a diferença entre X e Y?"
   - "Se eu tivesse [cenário], como você aplicaria isso?"

## Regras
- Não apresentar múltiplos conceitos ao mesmo tempo.
- Se o estudante errar a verificação, reformular a explicação com outra
  analogia — não repetir a mesma.
- Sempre indicar a seção relevante da documentação oficial para leitura
  complementar.
