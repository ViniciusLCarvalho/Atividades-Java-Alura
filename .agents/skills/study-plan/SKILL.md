# Plano de Estudos

## Procedimento

### Passo 1 — Levantamento de dados (fazer UMA pergunta por vez)
Coletar 4 informações essenciais antes de montar o plano:
1. **Objetivo de carreira**: O que o estudante quer alcançar? (ex: primeiro emprego como dev Java, migração de carreira, certificação)
2. **Nível atual**: Iniciante completo, sabe lógica mas não Java, intermediário, etc.
3. **Tempo disponível**: Quantas horas por dia/semana e em quais dias.
4. **Prazo final**: Existe uma data-alvo? (ex: processo seletivo em 3 meses)

### Passo 2 — Montar trilha lógica
Organizar o conteúdo seguindo esta progressão (adaptar ao nível do estudante):

```
Fundamentos (lógica, algoritmos)
  ➔ Sintaxe Java (variáveis, tipos, operadores)
    ➔ Controle de fluxo (condicionais, laços)
      ➔ Métodos e arrays
        ➔ POO (classes, objetos, encapsulamento)
          ➔ Herança, polimorfismo, interfaces
            ➔ Collections e Generics
              ➔ Exceções e I/O
                ➔ Streams e Lambdas
                  ➔ Banco de Dados (JDBC, JPA)
                    ➔ Frameworks Web (Spring Boot)
                      ➔ Projetos integradores
```

### Passo 3 — Dimensionar duração
- Calcular com base na carga horária real informada.
- Regra prática: ~2-3h por conceito novo + exercícios para iniciantes.
- Incluir tempo de revisão (20% do total).

### Passo 4 — Definir marcos práticos
Criar entregas tangíveis para portfólio/motivação. Exemplos:
- "Semana 3: Entregar calculadora com menu no terminal"
- "Semana 6: CRUD de tarefas com ArrayList"
- "Semana 10: API REST com Spring Boot"

### Passo 5 — Recomendar fontes
Priorizar fontes oficiais e gratuitas:
- [dev.java](https://dev.java/) — Documentação oficial Java
- [docs.oracle.com](https://docs.oracle.com/en/java/) — Referência completa
- [spring.io/guides](https://spring.io/guides) — Tutoriais Spring
- [Alura](https://www.alura.com.br/) — Cursos que o estudante já utiliza
- [Baeldung](https://www.baeldung.com/) — Tutoriais práticos Java/Spring

## Formato de saída
Apresentar o plano como uma **tabela semanal** com: Semana, Tema, Atividades, Marco/Entrega, Fonte recomendada.
